# Rust crates

`model-maker-simplify` brings a shape to its triangle budget.

`model-maker-launcher` is the `model-maker` command and installer for Linux, Windows and macOS: it checks the PC
(`model-maker check`), sets it up (`model-maker setup`) and passes every other command to the Python side. Its pins
(uv, Python, llama.cpp) equal setup.sh's, checked by a test, until setup.sh hands over to it.

`model-maker-companion` is the small window for people who would rather not type commands
([`docs/companion.md`](../docs/companion.md)).
